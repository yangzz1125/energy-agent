# V0 模拟负荷数据

`load_sample.csv` 是人为构造的教学数据，不来自真实电网或公开数据集。

- 时间范围：2026-09-21 00:00 至 2026-09-27 23:00，固定 UTC+08:00。
- 采样粒度：每小时一条，共 168 条，无缺失或重复时间。
- `timestamp`：当前 CSV 格式为 `YYYY/M/D H:mm`，如 `2026/9/21 0:00`，表示该小时的开始时刻；统一使用东八区时间，字段中不附带时区偏移。
- `load_mw`：该小时的平均有功负荷，单位 MW，保留两位小数。
- 特征：凌晨低谷、上午和傍晚高峰，周末整体较低；未模拟节假日、天气或随机噪声。

生成规则：24 小时基础曲线依次为
`[52,49,47,46,47,52,63,78,91,96,92,87,83,81,83,87,94,105,113,109,98,84,69,58]` MW，
周一至周日分别乘以 `[1.00,1.03,0.98,1.05,1.01,0.88,0.85]`。

练习：计算某一天的最大、最小、平均负荷和峰谷差，比较工作日与周末，并画出负荷曲线。
该数据用于验证读取、统计和工具调用，不用于评估真实负荷预测效果。
